1. Requirements
Functional requirements
1. Create a task.
2. Update task details.
3. Delete a task.
4. Assign priority to a task.
5. Set a due date.
6. Retrieve the highest-priority task.
7. Retrieve tasks sorted by priority.
8. Retrieve tasks due within a given time period.
9. Mark a task as completed.
Non-functional requirements
- Efficient task retrieval.
- Support multiple tasks.
- Extensible priority and status models.
- Thread safety if multiple threads access the task manager.
