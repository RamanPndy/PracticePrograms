Core Gameplay

Snake moves continuously in one of four directions.

Player can change direction using touch controls or virtual buttons.

Food spawns randomly on the map.

When snake eats food:

Score increases

Snake grows

Food respawns

Game ends when:

Snake collides with wall

Snake collides with itself

Game States

Start

Running

Paused

Game Over

Restart game

Non-functional

Smooth rendering at 60fps

Platform independent (Android/iOS)

Maintainable code using OOP, design patterns

Configurable board size, snake speed
